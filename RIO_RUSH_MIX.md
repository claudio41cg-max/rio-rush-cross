# Turbo Kart Rush + Rio Rush RC Mix

This test uses the full Turbo Kart Rush game structure (MIT, BridgeMind, 2026)
and replaces only the player kart visual with the Rio Rush RC vehicle assets.
AI racers, tracks, race manager, items, HUD, audio and effects remain from Turbo Kart Rush.

The previous Rio Rush state is preserved in branch `backup-before-turbo-kart-mix`.
The version before the Portuguese translation is preserved in branch `backup-before-portuguese`.
